# 图片素材规格

界面图片资源位于 `public/`（Vite 原样拷入 `dist/`，代码按固定路径引用）。当前内容是程序生成的占位图（`python3 temp/gen_placeholders.py`，Pillow + 文泉驿字体，运行即覆盖 `public/` 下同名文件）；正式素材按下方规格**同名覆盖** `public/images/…` 与 `public/favicon.svg` 即可，无需改代码。**目录结构与文件名不可改。**

**定稿流程**：按下方规格生成正式素材 → 同名覆盖到 `public/` → `npm run build` → 按 README「部署」节部署验证。

**通用原则**：尺寸可比规格**更大**（2x 更清晰），但**宽高比必须一致**（`cover`/`contain` 裁切适配）；所有断点尺寸代码已适配，素材无需分倍率出图。

## 二、图标（`images/icons/`，24×24 viewBox，SVG）

**接入方式（重要）**：除奖牌外全部走 **CSS mask** —— 只用图形的 **alpha 通道**，颜色被忽略、统一跟随文字色。所以：**单色实心/描边形状即可**，`fill`/`stroke` 写什么色都行（黑白最稳）；图形必须**封闭可识别**（细于 1px 的线在 12px 显示下会糊）。

| 文件 | 含义 | 用在哪 |
|---|---|---|
| `dealer.svg` | 皇冠 | 庄家徽标（橙圆内，白色，11px） |
| `bot.svg` | 机器人 | 「电脑」徽标前缀（对局座位 / 房间列表） |
| `delegate.svg` | 方向盘 | 「托管」徽标前缀 |
| `glare.svg` | 怒目 | 「瞪」徽标（未出过牌，12px） |
| `host.svg` | 钥匙 | 「房主」徽标前缀（房间列表） |
| `win.svg` | 奖杯 | 单局「胜」徽标（12px） |
| `bomb.svg` | 炸弹 | 对局顶栏「倍率 ×N」前缀（倍率 >1 时变橙） |

## 四、占位说明

- 占位全部由 `temp/gen_placeholders.py` 程序生成，运行即覆盖 `public/` 下同名文件
- 占位外观：牌背=蓝斜纹+菱形、王牌=奶油底竖排字+星/冠、头像=蓝底剪影、绒布=FFT 噪声、图标=手写几何路径
